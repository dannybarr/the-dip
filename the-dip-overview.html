What it does

Dip Scanner

Every covered name actually down on the day or week, ranked by Dip Score, with catalyst read, RSI, volume signature, and a live price sparkline. Green days show few or no rows, by design; this is a dip tool, not a watchlist.

Full underwriting page

Per stock: thesis, desk note, a one-year chart with support and plan levels overlaid, the six-pillar breakdown, fundamentals, technicals, bull and bear case, risk flags, and covered peers.

Trade plan or a refusal

Entry zone, stop, two targets, risk-reward, model win rate, expected value, and volatility-adjusted size. Falling knives and names not in a dip get no levels published. That refusal is the product.

Live data architecture

measured vs judgment

Quotes, technicals and fundamentals come live from Financial Modeling Prep. Catalyst reads, moat and balance-sheet ratings and desk notes are analyst judgment, and are labelled as such. The scoring engine never changes between modes.

01 · SOURCE

FMP live feed

Real quotes, daily OHLC history, TTM ratios and key metrics, live sector P/E. Cached with per-field TTLs to respect the free tier.

02 · MERGE

Live builder

Real market data is merged with the desk's authored overlay into one StockInput. Real history drives RSI, ATR, SMA, drawdown and support.

03 · SCORE

Analyst engine

The unchanged six-pillar engine recomputes scores, verdict and trade plan on today's real tape. Only genuine dips are underwritten.

04 · RENDER

Terminal UI

Shared across the app through one cached fetch. Loading, empty and error states are first-class, not afterthoughts.

⚠
Graceful fallback. If the key is missing or the feed is rate-limited, the terminal drops to a simulated snapshot of the same 24 names, flagged with a clear banner. It never shows stale numbers dressed as live.

Run it

A React, Vite and TypeScript app. Add your FMP key, install, and start. Without a key it runs the simulated snapshot; with one it goes live.

# add your Financial Modeling Prep key
$ echo VITE_FMP_API_KEY=your_key > .env.local
 
$ npm install
$ npm run dev # localhost:8080
 
$ npm test # 21/21 passing
$ npm run build # code-split production build
